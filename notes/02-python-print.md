## Вывод и ввод данных
````python
#print - это команда вывода аргументов. 
print('Он сказал:"привет"')
#input -это команда для ввода данных пользавтелем. 
name = input() 
print('I', name)
#sep - это разделитель между аргументами по умолчанию там проблел, но ты можешь задать какой угодно.
print('My', 'name', 'Alexander', sep='_')
#end - это чем заканчивается строка, по умолчанию она переносится знаком \n, но ты можешь задать какой уогодно параметр. 
print('My_name', end='_')  
print('Alexander')
#\n - это знак переноса строки, по он всегда работает по умолчанию
````
